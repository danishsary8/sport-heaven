## Global constraints (from FE1, unchanged)

- Money is integer cents from the API; the browser never computes a price, total or fee (it only multiplies nothing — line totals come from the API).
- Customers see stock only as ok / low (1–3, with count) / out.
- No personal data or order tokens in URLs or logs; a guest's order token lives in sessionStorage for the tab.
- Copy: sentence case, buttons name the action, no all-caps eyebrows, no "A · B · C" strings.
- Every data view: skeleton (10 s → Retry), error + Retry, empty state.
- After each UI task: screenshots at 390×844 and 1366×900 (English; Khmer at least once per stage), no horizontal scroll at 390.
- TDD: MSW-backed Testing Library tests written first and seen failing.
